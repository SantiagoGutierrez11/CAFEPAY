# CAFEPAY

Sistema de gestión de pagos para recolectores de café, desarrollado para la
Cooperativa de Caficultores del Cauca - Caficauca.

## Descripcion

CAFEPAY es una aplicacion de escritorio para Windows que permite gestionar
el registro y calculo de pagos a recolectores de cafe. Desarrollado como
solucion para optimizar el proceso de nomina en temporada de cosecha.

## Funcionalidades

- Registro de recolectores de cafe
- Calculo automatico de pagos segun kilos recolectados
- Gestion de base de datos con Oracle Lite
- Historial de transacciones por recolector

## Tecnologias

- Lenguaje: C#
- Plataforma: Windows (aplicacion de escritorio)
- Base de datos: Oracle Lite
- Entorno de desarrollo: Visual Studio

## Requisitos previos

Antes de ejecutar la aplicacion es necesario:

1. Instalar Oracle Lite en el equipo
2. Ejecutar el script de base de datos para crear las tablas e insertar
   los datos iniciales

## Instalacion y ejecucion

1. Clona el repositorio
   git clone https://github.com/SantiagoGutierrez11/CAFEPAY.git

2. Instala Oracle Lite en tu equipo

3. Ejecuta el script SQL incluido en la carpeta /database para crear
   la estructura de la base de datos

4. Abre el archivo .exe para iniciar la aplicacion

## Contexto

Proyecto desarrollado para la Cooperativa de Caficultores del Cauca
(Caficauca), organizacion que agrupa a productores de cafe del departamento
del Cauca, Colombia.
